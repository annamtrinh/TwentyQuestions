# 20 Questions: Fast Food Edition

A Java console game. Think of a fast food chain, answer a few yes/no
questions, and the program guesses it.

## Concepts Used
- Nested if/else statements (a decision tree)
- User input with `Scanner`
- String comparison with `equalsIgnoreCase`

## How to Run
```
javac TwentyQuestions.java
java TwentyQuestions
```
